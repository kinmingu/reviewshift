## 수집·선정 순서

1. Electronics의 리뷰와 메타데이터 44개(10.83 GiB)를 먼저 내려받는다.
2. 파일마다 예상 크기와 SHA-256을 확인하고 다운로드 manifest를 남긴다.
3. 전체 리뷰를 배치로 읽되 첫 통과에서는 상품별 총량만 집계한다.
4. 90건 이상인 상품만 두 번째 통과에서 월별 집계한다.
5. 연속된 완료 월 3개, 월 30건 이상, 3개월 합계 150~600건인 후보를 만든다.
6. 리뷰 감성 방향은 선정 기준으로 쓰지 않고, 리뷰 양과 월별 균형만으로 후보 순서를 정한다.
7. 서로 다른 제품 유형 2개를 확인한 후 해당 3개월의 모든 별점 리뷰를 적재한다.
8. Electronics 검증 후 나머지 6개 카테고리도 같은 절차로 진행한다.

`월 30건 이상`은 초기 데이터 선정 조건일 뿐 통계적으로 충분하다는 뜻이 아니다. 전체
원천의 문구가 같은 서로 다른 리뷰를 단순 중복으로 제거하지 않으며, 선정 상품·기간 안에서
원천 식별 필드가 모두 같은 정확한 중복만 제거한다.
