# Amazon Reviews 2023 Appliances 데이터 감사

## 출처와 이용 시 주의

- 공식 배포: <https://huggingface.co/datasets/McAuley-Lab/Amazon-Reviews-2023>
- 프로젝트 설명: <https://amazon-reviews-2023.github.io/>
- 배포자 라이선스 답변: <https://huggingface.co/datasets/McAuley-Lab/Amazon-Reviews-2023/discussions/1>

배포자는 원 리뷰에 대한 별도 라이선스를 부여할 권한이 없다고 안내하며 연구 목적 사용과 윤리·법률 준수를 강조한다. 따라서 이 적재를 일반적인 상업 이용 허가로 해석하지 않는다.

## 조사·다운로드 범위

전체 Amazon 데이터가 아니라 Appliances만 조사했다.

| 용도 | 파일 | 크기 | SHA-256 |
|---|---|---:|---|
| 리뷰 | `full-00000-of-00002.parquet` | 203,130,070 B | `4f17de49a46153096667da63da12175f4486dfcb12a9a40b0b50352aabce339b` |
| 리뷰 | `full-00001-of-00002.parquet` | 189,276,322 B | `8e6954bbe79b561dd6e0bdf45b9183aed5688d02fb03d30147c145c5c05adb18` |
| 메타데이터 | `full-00000-of-00001.parquet` | 95,900,964 B | `01f31e5d78e3ed3c59c09b85eb9e18a883ee6c2cdcfc8a67cc377aa27bbfefc6` |
| 합계 | 3개 | 488,307,356 B (약 465.7 MiB) | - |

리뷰 고정 리비전은 `e4458357e3499c762fb83a8c721fde557b7d0e8d`, 메타데이터 고정 리비전은 `b8c2d3e0d68f6b868f96e4c6ee9ad2c4fb091522`다.

대용량 전송 전 HTTP Range로 스키마와 일부 row group만 확인했으며 전송량은 약 6.3MB였다. 이후 승인된 세 파일만 다운로드했고 크기와 SHA-256을 기록했다.

## 필드·형식 점검

리뷰 필드는 `rating`, `title`, `text`, `images`, `asin`, `parent_asin`, `user_id`, `timestamp`, `helpful_vote`, `verified_purchase`다. 메타데이터에는 상품명, 설명, 이미지, 카테고리, 집계 별점, `parent_asin` 등이 있다.

- timestamp는 Unix milliseconds이며 UTC로 변환했다.
- `asin`은 리뷰 대상 변형 상품, `parent_asin`은 상품군 연결 키로 사용했다.
- 표본과 전체 스캔에서 `asin != parent_asin`인 변형을 확인했다.
- 별점 1~5를 모두 유지했으며 높은 별점을 임의로 제외하지 않았다.
